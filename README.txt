=====================================================
  BABAR TRADERS BILLING SYSTEM - DESKTOP SOFTWARE
=====================================================

Aapka software mukammal tayyar hai aur nayi features bhi add kar di gayi hain!

-----------------------------------------------------
1. SOFTWARE KAISE CHALAYEIN (HOW TO RUN):
-----------------------------------------------------
Tareeqa 1 (Localhost Link):
- Browser mein kholein: http://localhost:8000
- Ya mobile / Wi-Fi par: http://192.168.0.109:8000

Tareeqa 2 (Desktop Shortcut):
- Desktop par "Babar Traders Billing" ke icon par double click karein.

Tareeqa 3 (Folder Se):
- "Start-Server.bat" par click karein (ye local server aur browser khud chala deta hai).
- Ya "Babar Traders.vbs" / "index.html" par double click karein.

-----------------------------------------------------
2. NAYI FEATURES (NEW FEATURES ADDED):
-----------------------------------------------------
1. 🔍 PO Number & Invoice Number Search:
   - "Saved Bills" ke card mein Search Box add kar diya gaya hai.
   - Sirf PO number (maslan 500) ya Invoice no (maslan 100) ya party ka naam type karein.
   - Foran mutaliqa bills filter ho kar samne aa jayengay. "Open" par click kar ke foran load karein!

2. 💾 Auto-Save on Print / Action (Khuda-ba-Khud Mehfooz):
   - Jab bhi aap "Print / Save as PDF", "Excel", ya "Word" par click karengay, software bill ko pehle khud ba khud save kar lega taakay aapka record kabhi zaya na ho.

3. 📊 Download Excel (.xls):
   - Top bar par "Excel (.xls)" ka button add hai.
   - Is par click karne se mojuda bill ki mukammal Excel sheet download ho jayegi jisay aap Microsoft Excel mein open aur edit kar saktay hain.

4. 📄 Download Word (.doc):
   - Top bar par "Word (.doc)" ka button add hai.
   - Is par click karne se bill ka poora format Microsoft Word (.doc) mein download ho jayega.

5. 📑 All Bills Sheet / Master Register (Excel):
   - Saved Bills ke card mein "All Bills Sheet" ka button hai.
   - Is par click karne se aapke tamam saved bills ka aik mukammal Excel Master Register download ho jata hai (Invoice No, Date, PO No, Party, Total, Sales Tax, Grand Total ke sath).

-----------------------------------------------------
3. TABS AUR DOCUMENTS:
-----------------------------------------------------
- Contractor Bill: Bank details aur Total Amount ke sath.
- Sale Tax Invoice: Sales tax (18%), Excluding Amount aur Grand Total ke sath.
- Delivery Challan: Mal ki delivery ke liye baghair rate/amount ke.
